## Match card update (team-versus layout)

The match list keeps the existing broadcaster sections and horizontal scrolling rows. Each match card now presents the home and away crests around a centered `VS`, the two team names, and the league/kickoff information. Live matches use an orange `TRỰC TIẾP` badge.

The public test workflow builds the Release variant using Android's generated debug signing key. This avoids repository secrets, but the resulting APK is for testing only and cannot update an installation signed with the previous production keystore. Restore the private production signing configuration before distributing production updates.
